# Установка и удаление

Требования: Armada ARM64, glibc >=2.39, Python >=3.12, systemd, nftables,
NFQUEUE/nft_queue в ядре, curl/getent/modprobe, Decky API v1 и root-плагины.
В исследованном Decky установка локального ZIP реализована в
frontend/src/components/settings/pages/developer/index.tsx и
backend/decky_loader/browser.py. Версия Decky на вашем Odin ещё не проверена.

1. Войти в GitHub, скачать ZIP и SHA256SUMS из приватного релиза. Проверить SHA256.
2. В Desktop Mode сохранить ZIP, например в Downloads.
3. Gaming Mode → Decky → Settings → Developer → установка из локального ZIP.
   При необходимости включить режим разработчика Decky. Выбрать
   zapret2-armada-v0.1.0-arm64.zip, не распаковывая его.
4. Zapret2 Armada → Диагностика → «Подготовить / обновить службу».
5. При отсутствии NFQUEUE/nft_queue остановиться. Плагин не устанавливает
   новое ядро и не меняет bootc-образ. Нужна Armada с соответствующей поддержкой.
6. Выполнить диагностику. Включить Zapret2 на главной, проверить nfqws2 и сайты.
7. При необходимости включить автозапуск отдельно. QUIC/UDP изначально выключен.

Служба и данные: /var/lib/zapret2-armada, /var/log/zapret2-armada,
/etc/systemd/system/zapret2-armada.service,
/etc/modules-load.d/zapret2-armada.conf. Запись в /usr не требуется.
После обновления плагина повторить подготовку службы для обновления её копии.

Домены: добавить/удалить строки в редакторе. Вставка списка — импорт.
Исключения имеют приоритет. Экспорт показывает JSON для копирования.
Профиль допускает только id/name/method/position/repeats; произвольный Lua и
командные строки не принимаются. Восстановление доменов добавляет набор
данной версии; интернет-обновлений сторонних списков в 0.1.0 нет.

Удаление: выключить Zapret2 и удалить плагин через Decky. Хук _uninstall
удалит только собственную службу, файл загрузки модулей, копию приложения и
свою таблицу. Настройки и логи сохраняются. Если Decky недоступен, из
проверенного распакованного ZIP выполнить `sudo bash scripts/uninstall.sh`.
Не выполнять `nft flush ruleset`.

Диагностика сохраняется в /var/lib/zapret2-armada/diagnostic-report.json и
показывается в интерфейсе для копирования. Отчёт содержит ваши домены и
сведения о системе: просмотрите его перед передачей.

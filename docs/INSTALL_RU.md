# Hysteria2 Armada: установка и проверка

Нужны Decky Loader с root-плагинами, ARM64 Linux, systemd и работающий
/dev/net/tun. Сервер Hysteria2 должен быть доступен по UDP. NFQUEUE не нужен.

1. Скачать hysteria2-armada-v0.2.0-arm64.zip и SHA256SUMS из релиза.
2. В Gaming Mode открыть Decky → Settings → Developer → установить локальный
   ZIP. Файл не распаковывать. Это обновление заменяет прежний плагин
   Zapret2 Armada в том же каталоге Decky.
3. В правой панели Decky открыть Hysteria2 Armada → «Сервер».
   Указать адрес, UDP-порт, пароль, пароль Salamander (если включён на сервере),
   TLS SNI при подключении по IP. Сохранить.
4. На главном экране включить «Hysteria2 VPN». Дождаться «Подключено через TUN».
   Проверить внешний IP и сайты через браузер, затем Steam и игру с UDP.
5. Выключить переключатель. Должно вернуться прямое соединение.
   Автозапуск после перезагрузки по умолчанию выключен.

Пароли хранятся только в root-доступных файлах
/var/lib/hysteria2-armada/settings.json и client.yaml. Логи из интерфейса
скрывают сохранённые значения паролей, но могут содержать адрес сервера.
Проверка сертификата включена по умолчанию. Переключатель пропуска проверки
сертификата снижает защиту и нужен только при особой конфигурации сервера.

При обновлении выключается только принадлежащая прежнему плагину служба
zapret2-armada.service и удаляется только его таблица inet zapret2_armada,
если совпадает маркер владения. Старые списки доменов остаются на диске.
При удалении нового плагина Decky останавливает VPN и удаляет его секреты.

Из-за отсутствия физического Odin 3 тест включения/выключения в Gaming Mode,
проверка внешнего IP, DNS, Steam Remote Play и игровых UDP-соединений пока
требуют проверки на устройстве.

# SpoofDPI Armada 0.3.0: установка и проверка

1. Скачайте `spoofdpi-armada-v0.3.0-arm64.zip` из релиза и установите его через
   Decky → Settings → Developer → Install plugin from ZIP. Архив не распаковывайте.
   Несмотря на новое название, Decky обновит прежний плагин в том же каталоге.
2. В игровой правой панели откройте SpoofDPI Armada и включите «Локальный
   обход DPI». Дождитесь состояния «SpoofDPI: прямой маршрут».
3. Проверьте внешний IP: он должен остаться вашим обычным IP, не IP сервера
   Hysteria2. Проверьте несколько нужных сайтов, Steam и UDP-игру; сравните
   игровую задержку с выключенным переключателем.
4. Если обход не помог, откройте «Стратегия DPI» и попробуйте усиленный TLS
   split. Для анализа запуска откройте «Логи DPI».
5. Выключите переключатель и убедитесь, что сайты и игры работают напрямую.

Отдельный переключатель Hysteria2 VPN доступен после настройки «Сервер VPN».
При его включении локальный режим останавливается. Одновременно два режима
включить нельзя. VPN повышает задержку на путь до удалённого сервера.

Нужны ARM64 Linux, Decky с разрешением root-плагинов, systemd, команды `ip`
из iproute2 и `/dev/net/tun`. NFQUEUE и nf_conntrack для локального режима не
нужны. IPv6 SpoofDPI TUN v1.5.5 не перехватывает. Если TUN недоступен, плагин
покажет ошибку, а служба не будет включена.

Поскольку тест на физическом Odin 3 пока не проведён, работу конкретных
сайтов и игр на Armada OS нельзя гарантировать до этой проверки.
